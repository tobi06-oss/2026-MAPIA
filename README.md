# 가면 뒤의 진실, 종갓집 자객 소동

밀양 종가고택 모임(10명)을 위한 오프라인 마피아 게임 사회·투표 앱입니다.
각자 인터넷이 되는 폰으로 접속하고, 토론은 얼굴 보고 진행합니다.

## 사용법
1. 집사(사회자) 한 명이 페이지를 열고 **고택 열기**를 누릅니다.
2. 나머지는 집사 화면의 초대 QR이나 4자리 문패 코드로 **고택 입장**합니다.
3. 집사가 설정을 확인하고 **호패 나눠주고 시작**을 누르면 게임이 시작됩니다.

## 구성
- `index.html` 한 파일로 동작합니다 (배경 그림 포함).
- 폰끼리는 PeerJS(WebRTC)로 연결되고, 집사 폰이 게임 진행을 맡습니다.
